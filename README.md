## 📂 Featured Projects

### 🤖 Advanced RAG Assistant

An advanced PDF question answering application built to explore document-grounded answers, retrieval quality, and conversational interactions.

**Tech stack:** Python · LangChain · OpenAI API · ChromaDB · BM25 · Streamlit

**Features**
- **Parent-child retrieval:** Finds focused chunks and supplies broader source context.
- **Hybrid retrieval:** Combines BM25 keyword search with vector similarity search.
- **Multi-query retrieval + RRF:** Generates query variations and combines ranked retrieval results.
- **Contextual compression:** Focuses the retrieved context supplied to the language model.
- **Conversational memory:** Supports follow-up questions across chat turns.
- **Document-grounded answering:** Includes fallback handling for questions unsupported by the document.
- **Evaluation:** Assesses groundedness, context relevance, Hit@K, and MRR.
- **Streamlit chat interface:** Provides an interactive way to use the assistant.
- **Retrieval debugging:** Helps inspect search results and understand retrieval behavior.

🔗 [Explore Advanced RAG Assistant](https://github.com/ragulpazhamalai/advanced-rag-assistant)
